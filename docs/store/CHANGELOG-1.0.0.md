# QuarkOS Emotes 1.0.0

Initial content prepared for the first release:

- Sixteen editable emotes: wave, thinking, facepalm, table flip, clap, bow,
  salute, laugh, dab, sit, groove, spotlight dance, shrug, point, cheer,
  and stretch.
- Looping reactions and dances, plus held sit and table-flip poses.
- An authored oak-table cube prop and timed vanilla sound cues.
- English emote-name entries for integration into the runtime language file.
- Blockbench authoring and replacement documentation, with an offline
  content validator.

**Verification pending:** Fabric and Forge on Minecraft 1.21.1/1.21.11,
runtime parsing, rendering, props, sounds, selection controls, resource
overrides, and optional multiplayer synchronization. No screenshots or
published release files are claimed by this content changelog.
